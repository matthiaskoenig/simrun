# Release notes for simrun 0.3.2

A release for the tests: the package is the same as 0.3.1.

## Fixes

- The k3d tests try the download of their tools (k3d, kubectl) again after a server error or a network error, up to five times with a growing pause, instead of failing at once: a gateway timeout of GitHub failed the cluster job of the release 0.3.1. An error of the client, e.g. a missing file, still fails at once.

## Upgrading

- Nothing to do.
